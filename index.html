전체 백업 파일 저장
근무자 명단, 모든 달의 근무 기록, 주간 배치, 시급·주휴수당 설정까지 전부 하나의 JSON 파일로 저장해요. 복원용으로 쓰는 파일이에요.

백업 파일 불러오기
저장해둔 JSON 백업 파일을 선택하면 그 시점 상태로 전부 복원돼요. 현재 입력 중인 내용은 덮어쓰기 되니 주의하세요.
📊
전체 기간 Excel 내보내기
입력된 모든 정산월의 근무 기록과 임금 계산을 월별 시트로 담아 엑셀 파일로 저장해요. 보관·제출용으로 좋아요.

전체 데이터 인쇄
근무자 명단, 주간 배치, 입력된 모든 달의 근무 기록과 임금 내역을 한 문서로 정리해 종이로 출력해요.
